# Ball Runner

A small browser platformer made with plain HTML, CSS and JavaScript. It has no server, no backend and no dependencies.

Roll the ball through 3 short levels (about 90 seconds in total). Jump over walls, spikes and pits to reach the flag.

## Controls
- **← →** move
- **↑ / Space** jump (hold it longer to jump higher)
- **R** restart the current level

## Run it
Open `index.html` in any browser, or play it online with GitHub Pages.
