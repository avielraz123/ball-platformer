# Ball Runner

A small browser platformer made with plain HTML, CSS and JavaScript. It has no server, no backend and no dependencies.

Roll the red ball through 6 levels to reach the flag:
- **Obstacles:** walls, spikes and pits
- **Enemies:** green slimes that walk back and forth (jump on them to squash them)
- **Obstacles that chase you:** spiked wheels that roll toward the ball, and spike mines that fly after it
- **Weapons:** you start with a Blaster. Pick up the Triple Shot or the Bomb Launcher in the levels (they have limited ammo).
- **Skins:** 8 ball skins (Classic Red, Ocean Blue, Lime, Gold, Soccer, Watermelon, Ninja, Rainbow). The game remembers your choice.
- **Bosses:** King Blob (level 3) and Spike Lord (level 6). Jump on their heads to beat them.

Add `?level=N` to the URL to jump straight to level N (for example `?level=3` for the first boss).

## Controls
- **← →** move
- **↑ / Space** jump (hold it longer to jump higher, press again in the air to double jump)
- **R** restart the current level
- **N** skip to the next level, **B** go back a level
- **D** turn double jump on/off
- **X / F** shoot
- **S** change ball skin (or ← → on the title screen)

## Run it
Open `index.html` in any browser, or play it online with GitHub Pages.
